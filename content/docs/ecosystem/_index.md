First-party companion modules that live alongside core Velocity. Each ships as its own Go module under `github.com/velocitykode`, so it stays out of the core dependency graph and is opt-in: you add only what you need with `go get`. The AI-facing modules live in the [AI]({{< relref "/docs/ai" >}}) section.
